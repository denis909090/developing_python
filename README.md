Тема: Імплементація та маніпуляції основними типами та структурами даних у Python
Мета роботи
Набути практичних навичок роботи з вбудованими типами та структурами даних Python — списками, кортежами, словниками та множинами: створення, індексація, зрізи, модифікація, comprehension-вирази. Дослідити алгоритмічну складність типових операцій та обґрунтовано обирати структуру даних для конкретних задач. Результатом виконання є відтворюваний код, оформлений звіт і експериментальні дані, що демонструють розуміння відмінностей між структурами та їхньою придатністю для типових операцій.

структура проекту
- task_1.py - Списки. індексація, зрізи, мутації
- task_2.py - Кортежі. розпакування, агрегати, immutability
- task_3.py - Словники. частотний аналіз тексту
- task_4.py - Множини. операції над множинами
- task_5.py - Порівняння продуктивності list/set/dict
- num.txt - Вхідні дані для task_1.py
- text.txt - Вхідний текст для task_3.py
- result.txt - Результат роботи task_3.py 
- README.md - файл README.md з інструкціями запуску та requirements.txt

Що використовується
- Зовнішні бібліотеки не використовуються — лише стандартна бібліотека
Файли num.txt і text.txt мають лежати в тій самій папці, що й .py файли.
task_3.py після запуску перезаписує файл result.txt.
